# AGENTS.md

Community recovery of the deleted `Yu9191/wloc` (baseline `529fcd8`): an iOS Apple network-location spoofer. Two halves: MITM proxy modules (`modules/`, `dist/`) and a Cloudflare Worker (`worker/`) that serves the point-picking page and the `/api/parse` map-link parser used by Shortcuts. All user-facing docs, comments, and commit messages are in Chinese — keep them that way.

## Commands (run from repo root)

- Setup: `npm --prefix worker ci` (and `npm --prefix vercel ci` if working on the Vercel adapter) — the root `package.json` has no dependencies; `worker/` and `vercel/` have separate lockfiles. Node >= 22 (`.nvmrc`, `engines`), ESM only.
- Local verification, mirror CI order: `npm run check` → `npm test` → `npm run build:check` → `npm run pages:build`.
- Single test: `node --test worker/test/parse.test.mjs` (plain `node:test`, no framework, no services needed).
- `build:check` / `pages:build` are dry-run/local only (output to `build/`). Only `npm --prefix worker run deploy` / `pages:deploy` touch Cloudflare.

## Generated files — do not edit directly

- `modules/wloc.*` (all 5 client modules), the README block between `<!-- subscriptions:start/end -->`, and `worker/src/project.js` are generated by `npm run configure` from `templates/modules/` + `project.config.json`. Edit the templates/config, regenerate, then commit both.
- `vercel/src/` is a byte copy of `worker/src/` made by `npm run sync:vercel`. Edit `worker/src/`, re-sync, commit both; `npm run check` fails on drift. The copy exists because the Vercel adapter must be self-contained: on Vercel only `vercel/node_modules` is installed, and Node resolution never reaches a sibling directory's `node_modules` — so never import `../worker/...` from `vercel/` at runtime.
- `npm run check` fails on stale generated files, stale upstream hashes, old upstream URLs in modules, and dead local Markdown links. `npm run check:release` additionally requires a real `repository` in `project.config.json`.
- Line endings: repo enforces LF (`.gitattributes`); `check` hashes LF-normalized content, so CRLF in templates will break it.

## `dist/` is frozen upstream bytecode-equivalent

`dist/wloc.js` and `dist/wloc-settings.js` are upstream prebuilt proxy scripts with **no build system in this repo** (the original source project was never recovered — see `docs/PROVENANCE.md`). Their SHA-256 is pinned in `docs/upstream-integrity.json` and enforced by `npm run check`. Do not reformat, prettify, or treat a formatted dump as recovered source (CONTRIBUTING.md explicitly forbids this). Changes require a stated source, regression tests, and a deliberate integrity-record update. Known unfixed bug: `wloc-settings.js` uses truthiness on lon/lat, so coordinate `0` breaks — fix only after adding an independent regression test (see `docs/MAINTENANCE.md`).

## Worker conventions

- Entry `worker/src/index.js` (Hono app); `parse.js` = map-link parsing + GCJ-02/BD-09 → WGS84 conversion; `page.js` = the inline HTML page; `functions/[[route]].js` reuses the same app for the Pages variant — keep all three deployment paths working (`wrangler.jsonc`, `wrangler.pages.jsonc` with the same `compatibility_date`, and `vercel/`).
- Vercel adapter (`vercel/`): zero-config Hono deployment with project Root Directory = `vercel`. `vercel/index.js` must keep the bare `import "hono"` — Vercel's entrypoint detection regex rejects subpath imports like `hono/tiny`. Unlike the Cloudflare config, Vercel retains function runtime logs (request URLs contain coordinates) and they can't be fully disabled.
- No `nodejs_compat` on purpose: `worker/src` must use standard Web APIs only.
- Privacy constraints are deliberate, don't "fix" them: `observability.enabled = false`, `Cache-Control: no-store` on `/api/*`, and CORS headers on **all** responses including 500s (Shortcuts otherwise surfaces a cross-origin error instead of the real one — `http.test.mjs` covers this).
- `npm test` must keep running both `*.test.mjs` and `*.test.js` — the `.js` Stash test executes `dist/wloc.js` in a `node:vm` sandbox and was silently skipped by upstream's test glob.

## Claims and secrets

- Never claim iOS 27 support or client compatibility from unit tests alone; unverified compatibility claims must be marked 待验证 (`docs/MAINTENANCE.md`). Real-device results must include client version, iOS version, network, GPS presence.
- Never commit tokens, cert private keys, `.dev.vars`, real location data (already gitignored: `*.pem`, `*.key`, `.env*`, `/.dev.vars*`).
